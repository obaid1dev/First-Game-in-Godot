# 🎮 My First 2D Platformer

A 2D platformer game made using the **Godot Engine**, created by following the tutorial by [@Brackeys](https://www.youtube.com/@Brackeys).

---

## 🌟 About the Project

This project is my entry into game development using Godot! It features basic 2D platforming mechanics including player movement, jumping, coin collection, hazard collision, and scene transitions.

### Key Features
- 🏃 **Player Movement:** Smooth walking, running, and jumping mechanics.
- 🪙 **Collectibles:** Coins with animated sprites and pickup sounds.
- ⚠️ **Hazards & Enemies:** Basic obstacle detection and restart logic.
- 🎨 **Pixel Art Graphics:** Animated sprites using Godot's built-in animation tools.
- 🎵 **Sound & Audio:** Audio players for background music and sound effects.

---

## 🚀 How to Play

### Prerequisites
To run or edit this project locally, you will need to have **Godot Engine 4.x** installed. You can download it from [godotengine.org](https://godotengine.org/).

### Running the Game
1. **Clone the repository:**
   ```bash
   git clone https://github.com/obaid1dev/First-Game-in-Godot.git
   ```
2. **Open Godot Engine:**
   - Click on **Import**.
   - Navigate to the cloned project folder and select the `project.godot` file.
   - Click **Import & Edit**.
3. **Play:**
   - Press `F5` in Godot to run the main scene!
